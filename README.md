🏥 Hospital Management System

A Smart Hospital Management System built using Python, Streamlit, and SQLite. This project aims to provide a simple, user-friendly web application for hospital-related management.

🚀 Technologies Used

- Python
- Streamlit
- SQLite

✨ Features

- Interactive web-based interface
- Hospital management functionality
- Database integration using SQLite

🛠️ Installation & Setup

1. Clone the repository:
   
   git clone https://github.com/kanu2006/Hospital-app.git

2. Open the project folder:
   
   cd Hospital-app

3. Install the required dependencies:
   
   pip install -r requirements

4. Run the application:
   
   streamlit run app.py

🎯 Project Objective

To gain practical experience in Python development, database management, and building interactive web applications.
